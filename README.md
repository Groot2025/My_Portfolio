# GitHub Portfolio

Static portfolio site ready for GitHub Pages.

## Edit Before Publishing

- Replace `Portfolio` with your name or brand in `index.html`.
- Update the GitHub, LinkedIn, and email links in the contact section.
- Replace any project descriptions that need different wording.
- Add real repository links inside each project card when available.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `portfolio`.
2. Upload these files or push this folder with git.
3. In GitHub, open `Settings` -> `Pages`.
4. Set the source to `Deploy from a branch`.
5. Choose the `main` branch and `/root`, then save.

Your portfolio will be available at:

```text
https://YOUR-USERNAME.github.io/portfolio/
```

For a user-site URL, name the repository `YOUR-USERNAME.github.io`.
